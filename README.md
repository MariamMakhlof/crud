# CRUD User Manager

A small CRUD demo built with React, React Router, Redux Toolkit, and Bootstrap. Create, edit, and delete sample user records. Changes are saved in the current browser using local storage; there is no backend or shared database.

## Run locally

```bash
npm install
npm start
```

## GitHub Pages

The project deploys from the `master` branch using GitHub Actions. After a successful deployment, visit <https://mariammakhlof.github.io/crud/>.
